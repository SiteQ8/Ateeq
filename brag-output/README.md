# فيديو الإطلاق

فيديو عمودي (1080×1920، ثلاثون إطارًا في الثانية، 24 ثانية) يفتح بالآية التي سُمّي التطبيق منها ﴿وليطّوّفوا بالبيت العتيق﴾ ثم يعرّف بعتيق ويُظهر أنه متوفّر على App Store، والتعليق الصوتي بلهجة كويتية.

- `brag.mp4` الفيديو النهائي
- `brag.jpg` صورة الغلاف، وهي أيضًا الإطار الأول من الفيديو ليظهر كصورة مصغّرة في كل مكان
- `share-copy.txt` نص النشر بالعربية والإنجليزية
- `narration.mp3` التعليق الصوتي كما هو قبل المزج
- `composition/` مصدر الفيديو كاملًا

## نص التعليق

> يا حاج ويا معتمر، عتيق وياك خطوة بخطوة، في كل محطة تعرف شنو تسوي وشنو تقول وشنو تنتبه له، عداد للطواف والسعي، والأدعية في مواضعها، وتنبيه الإحرام في الطائرة، وكله يشتغل بدون إنترنت، عتيق، حمله الحين من Apple Store.

## إعادة البناء

كل إطار دالة خالصة في الزمن داخل `composition/comp.html`، لذلك يخرج الفيديو نفسه في كل مرة:

```sh
cd brag-output/composition
npm i playwright && npx playwright install chromium
node render.mjs                  # الإطارات ثم المزج الصوتي ثم brag.mp4 و brag.jpg
node render.mjs stills 0.5,4.7   # لقطات للمراجعة في stills/
```

الشاشات داخل الهاتف لقطات حقيقية من التطبيق، والمؤثرات الصوتية من Kenney برخصة CC0، وشارة App Store هي شارة Apple الرسمية دون تعديل.
